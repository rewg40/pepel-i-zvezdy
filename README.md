# Пепел и Звёзды

Проект 3D-игры о выживании на заражённом острове. Здесь собраны 3D-модели, референсы и данные растительности.

## Структура

| Папка | Содержимое |
|---|---|
| `остров/` | Материк: две версии острова (GLB), рендеры «до/после», маски биомов (`eye_forest/snow/steppe`), референсы, `растительность_точки.json` — точки леса/травы для Godot MultiMesh |
| `зараженный остров/` | Заражённая зона: модель (GLB) и референс-рендеры от разных генераторов |
| `зомби/` | Модель зомби (GLB) |
| `персонаж/` | Игровые классы: медик, инженер, строитель, военный (GLB) |
| `предмет/` | Меч «Dragon Broadsword with Cyan Hilt» (GLB) |
| `game/` | **Godot-проект** (отдельная папка игры): карта, медик с мечом, 3 зомби с отрубанием конечностей. Открывать `game/project.godot`. См. `game/README.md` |
| `tools/` | Python-пайплайн, которым собраны игровые ассеты в `game/models/` (распаковка архивов, децимация, риг, скины, анимации, атлас, карта высот) |

## Примечание о моделях

GLB-файлы исключены из репозитория через `.gitignore` (`*.glb`): их суммарный вес ~660 МБ, а `остров/2 остров улучшенный.glb` (114 МБ) превышает лимит GitHub в 100 МБ на файл. Модели хранятся локально в `D:\my games\Godot\Пепел и Звёзды`.
